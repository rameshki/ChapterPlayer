## How work was done (keep doing it)
- Per feature: write a plan in `docs/superpowers/plans/<date>-<name>.md` (goal, constraints, tasks, finish checklist, report path), branch `stage-N/<name>` or `fix/<name>`, dispatch an implementer subagent (opus for judgment-heavy, sonnet for UI and mechanical work) with only the plan path, then an independent review subagent on the diff (opus for sync/concurrency/security, sonnet otherwise), ONE fix wave via SendMessage to the implementer, push, open the PR, watch CI, squash merge. Robert approves designs through mock-ups (private HTML artifacts) before bigger UI work and said "your call, decide and go forth" for ordering.
- Commit trailers: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01M55YRaxmRRG8NmDaVhSmey` (implementers sometimes write the wrong model name; fix with `git filter-branch --msg-filter` before pushing). PR bodies end with the "Generated with Claude Code" line plus the session URL. Implementers never push and never dispatch subagents.
- Merge: `gh pr merge N --squash --delete-branch --subject "Title (#N)"`. `main` is protected and strict: when another PR merged first, the branch must be rebased onto `origin/main` and CI re-run (use a throwaway worktree to rebase a branch without disturbing the checkout an agent is working in).
- CI has two jobs: "Build & unit test" (~3 min) and "iOS framework & app shell" (macOS, ~12 to 14 min) which compiles `commonMain` with Kotlin/Native. **Windows cannot check that**: never use JVM-only calls in `commonMain` (`putIfAbsent`, `computeIfAbsent`, `String.format`, `java.*`, `System.currentTimeMillis`, `sortedMapOf`); this already failed CI twice. `compileCommonMainKotlinMetadata` reports unrelated errors locally in `ServerSetupScreen.kt`.
- Usage limits: opus and session limits stop agents mid-task (the work stays saved in the tree/commits). Resume with SendMessage to the same agent once the limit resets, or start a sonnet agent on the same plan.
- Windows quirks: the working tree is CRLF (grep after edits); edit files from Python with `encoding='utf-8'` (em dashes in sources); Git Bash rewrites `/sdcard/...` unless `MSYS_NO_PATHCONV=1`; `sleep` followed by a long wait is blocked, use `gh run watch <id> --exit-status` instead; JDK 17.

## Testing on devices
- Emulator AVD `ChapterPlayer_Pixel` (Android SDK emulator). If it hangs or `adb` shows it `offline`: kill `qemu-system-x86_64.exe` and `emulator.exe` by PID, delete `*.lock` in the AVD folder, start with `-no-snapshot -no-audio -gpu swiftshader_indirect`, wait for `sys.boot_completed`. Driving the UI works with `adb shell uiautomator dump` + `input tap`, but text fields lose the first characters unless you tap, wait ~1.5 s, then type.
- Robert's phone over wireless debugging: he turns on Wireless debugging, `adb pair <ip:pairport> <code>` (the code and pairing port only work while his dialog is open), then `adb connect <ip:mainport>` (the main port changes; `adb mdns services` shows it). Use `adb -s <device id> ...` because the emulator is also attached. Install the DEBUG build (package `com.chapterplayer.debug`, separate data from the release app). Read logs with `adb logcat -s ChapterPlayerHttp` (auth headers are redacted); never read his screen or other apps; the database can be copied with `run-as` for diagnosis, titles in it are his real library: never put them in the repo.
- Handing him an APK: build `:androidApp:assembleRelease`, `zipalign`, sign with the local debug keystore (`apksigner`), send the 7 MB file with the SendUserFile tool (limit 30 MiB; the debug APK is 31 MiB and cannot be sent). Uninstalling the app wipes downloads and tokens but Android's Google backup restores the Room data (server list, library); tokens and `downloads/` are excluded from backup.
- Real Audiobookshelf checks use a throwaway user created through the admin API (with the download permission when testing downloads) and deleted afterwards; never write with the owner's token; never put tokens or passwords in prompts to subagents, OpenClaw or the repo.

## Rules that must not be broken
- Public repo: no real server addresses, ids, titles, library names, tokens or passwords in commits, tests, docs or PR text (fixtures keep real structure with synthetic text). Scan every diff before pushing.
- Tokens never in URLs, logs, exceptions, notifications or media metadata; auth headers are redacted in the HTTP logger; the Plex token goes only to the server's own verified origins; no redirects to another host with a token.
- Never remove DRM. ComfyUI is irrelevant, never raise it. Pronouns: they/them unless stated.
