# Stage 1, PR 1: Toolchain upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the single-module Android app to Kotlin 2.4, AGP 9.3 and Gradle 9.5 with no change in behavior, and drop kapt in favor of KSP.

**Architecture:** One module (`app/`) stays one module. This PR only changes build tooling: Gradle wrapper, version catalog, plugins, annotation processing (kapt to KSP) and the Compose compiler setup. Source changes are limited to what the new compilers force.

**Tech Stack:** Gradle 9.5.0, AGP 9.3.1 (built-in Kotlin), Kotlin 2.4.21, KSP 2.3.12, Compose Compiler Gradle plugin, Hilt 2.60.1, Room 2.8.5, Compose BOM 2026.09.00.

**Spec:** `docs/superpowers/specs/2026-10-12-stage-1-kmp-migration-design.md` (PR 1 row). This plan amends it in two places, recorded in Task 7: kapt is removed in this PR instead of kept beside KSP, and `compileSdk` becomes 37.

## Global Constraints

- Behavior must not change: Library, Settings and Add Server render and work as on `main` at commit 54385e0.
- `applicationId` stays `com.chapterplayer`; debug keeps the `.debug` suffix. `minSdk` 26 and `targetSdk` 34 do not change.
- JDK 17 must still build the project (CI uses Temurin 17; this machine has Temurin 17.0.20).
- Auth headers stay redacted in debug HTTP logging (`NetworkModule.kt`). Do not touch that logic.
- No new features and no refactors beyond what the toolchain forces.
- Branch is `stage-1/toolchain`, created from `main`. Commits end with the two attribution lines from the session reminder.
- Run all commands from the repo root `C:\Users\Robert\ClaudeProjects\ChapterPlayer`. Gradle needs `JAVA_HOME` set to JDK 17 (it already is on this machine).

## Version decisions (checked 2026-10-12)

| Item | Version | Why |
|---|---|---|
| Gradle | 9.5.0 | Minimum for AGP 9.3; inside Kotlin 2.4.21's supported range (up to 9.7.0) |
| AGP | 9.3.1 | Newest AGP inside Kotlin 2.4.21's fully supported range (8.5.2 to 9.3.1). AGP 9.4.x exists but needs Gradle 9.6 and is outside that range |
| Kotlin | 2.4.21 | Latest stable |
| KSP | 2.3.12 | Latest; notes mention Kotlin 2.4 and AGP 9 built-in Kotlin fixes; needs AGP 8.12 or newer |
| Hilt | 2.60.1 | Latest; supports KSP |
| Room | 2.8.5 | Latest; supports KSP |
| compileSdk | 37 | `core-ktx` 1.19.1 and `navigation-compose` 2.10.2 declare `minCompileSdk=37`; AGP 9.3 supports up to API 37 |
| Build tools | 36.0.0 | AGP 9.3 minimum |
| foojay resolver | 1.0.0 | 0.10.0 predates Gradle 9 |

- [ ] **Step 1: Loop until `./gradlew :app:assembleDebug` succeeds**

For each error, find the row below that matches, apply the fix, rebuild. Commit when a fix is complete and the error class is gone.

| Error contains | Cause | Fix |
|---|---|---|
| `The 'org.jetbrains.kotlin.android' plugin is no longer required` or `Cannot add extension with name 'kotlin'` | A plugin still applies `kotlin-android` | Remove any remaining `kotlin-android` alias or id. Task 3 and Task 4 already removed them; search with `grep -rn "kotlin.android\|kotlin-android" --include=*.kts --include=*.toml .` |
| `Unresolved reference` for a `kotlinOptions` or `composeOptions` symbol | Old DSL block left behind | Delete the block; the replacements are already in Task 4 |
| An error naming a property in `gradle.properties` as removed or unsupported (for example `android.nonTransitiveRClass`, `android.useAndroidX`) | AGP 9 changed defaults and removed some flags | Delete exactly the property the message names. These two are defaults in AGP 9 |
| `Cannot access class` or `Unresolved reference` in code that used a kapt-generated class (Hilt `Hilt_*`, `*_Impl`, Moshi `*JsonAdapter`) | KSP did not run, or the `ksp(...)` line is missing | Confirm `ksp(libs.hilt.android.compiler)`, `ksp(libs.room.compiler)` and `ksp(libs.moshi.kotlin.codegen)` are present; run `./gradlew :app:kspDebugKotlin` and read its output |
| `Dagger/MissingBinding` or similar Hilt error | KSP Hilt is stricter than kapt about nullability and visibility | Fix at the line named in the error; do not suppress |
| `Unsupported Kotlin plugin version` or `KSP ... requires Kotlin` | KSP and Kotlin out of step | Confirm `ksp = "2.3.12"` and `kotlin = "2.4.21"`; if the error persists, stop and report it, do not guess other versions |
| `Duplicate class` | A transitive dependency now brings a second copy of a library | Run `./gradlew :app:dependencyInsight --configuration debugRuntimeClasspath --dependency <name>` and report the finding before excluding anything |
| Deprecation warnings only | Not errors | Leave them; list them in the PR description |
