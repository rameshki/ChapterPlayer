## New model
- `SourceChoice` (pure, commonMain): `Ask`, `OfType(ServerSource)` (Audiobookshelf or Plex) and `OfServer(serverId)` (one specific server; only offered in the UI when the user has 2+ servers of that type). Serialised to one string in DataStore (`ask`, `type:ABS`, `type:PLEX`, `server:<id>`); a deleted server's choice falls back to `Ask` (and the UI says so).
- **Two settings:** `downloadSourceChoice` and `playSourceChoice` (both default `Ask`). Remove `PREFER_DOWNLOADED` as an option: **a downloaded copy ALWAYS plays first** (a rule, not a setting). The old stored `source_preference` migrates once: ASK -> both Ask; PREFER_ABS -> both `OfType(ABS)`; PREFER_PLEX -> both `OfType(PLEX)`; PREFER_DOWNLOADED -> both Ask (the old default never asked; Robert wants asking).
- **Download:** the Download control picks the copy by `downloadSourceChoice`: `Ask` -> the source sheet (rows per downloadable copy with server name, type, size, reachability); `OfType`/`OfServer` -> that copy without asking when it exists, is reachable and downloadable, otherwise ask. A copy already downloaded is shown as downloaded (no second download unless the user asks via the sheet's "Download this copy too").
- **Play:** order: (1) a downloaded copy plays at once (if several are downloaded, the copy played last, else the first); (2) otherwise `playSourceChoice`: `Ask` -> the sheet; `OfType`/`OfServer` -> that copy if it can play now, else ask (explain why a copy is greyed: offline, server unreachable, Plex unplayable format). Home Resume, the car, the widgets and notifications keep resuming the copy played last (as now) unless that copy cannot play, then the same rule.
- **Primary copy ranking** (what the lists show for a merged book): downloaded first, then a copy matching `playSourceChoice`, then reachable, then ABS (as before otherwise). `PREFER_DOWNLOADED` logic is removed from rules and tests.
- **UI (Settings, Downloads and offline page, and mirror in the Settings hub summary):** two cards in a group "Books on several servers": "Download from" and "Play from (when not downloaded)". Each opens a dialog with radio lines: "Ask every time", "Audiobookshelf", "Plex", and, when 2+ servers of a type exist, indented lines with the server names ("Audiobookshelf: <name>", "Plex: <name>"). Each line has a one-line explanation; the Play card states "A downloaded copy always plays first." The Settings hub summary for Downloads and offline shows both choices briefly.
