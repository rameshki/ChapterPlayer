## 1. Filter by server (test-first)
- Pure rule in `domain/browse/BrowseFilter.kt`: `BrowseQuery` gains `serverIds: Set<String>` (empty = all servers). `applyFilter` keeps only books whose `book.serverId` is in the set. Persist it with the other saved filters (`BrowseQueryStore`; mind DataStore keys and the in-memory test store); a server that is deleted must drop out of the saved set, and an empty result because of a stale id must not hide the whole library (treat ids that no longer exist as "all").
- UI: in the Library filter sheet add a "Server" section (checkboxes, one per added server, showing the server name and a small type label ABS/Plex), shown only when two or more servers exist; the filter chip row gets a chip showing the active server filter ("Home server" / "2 servers") that opens the sheet or clears it. The filter applies in Library (all views: Library, Authors, Narrators, Series, Collections lists via the books they group), Home shelves and Search, like the existing saved filters. Counts: show the number of books per server in the sheet (from the unfiltered list).
- Tests: filter rule (empty, one, several, stale ids), store persistence, view-model state, sheet state.

## 2. A to Z fast scroller
- Pure rules in `domain/browse/FastScroll.kt`: `fastScrollLetters(keys: List<String>): List<LetterIndex(letter: Char, firstIndex: Int)>` from the already sorted list of display keys (title for the Title sort, author for the Author sort, the group title for Authors/Narrators/Series/Collections lists): letter = first letter ignoring a leading "The ", "A ", "An " (reuse `domain/car/CarRules.kt` `titleLetter`, which maps non letters to '#'), only letters that occur, in list order; plus `letterAtFraction(letters, fraction)` and `indexForLetter`. Offer the scroller only when the active sort is Title or Author (the other sorts are not alphabetical) and for the alphabetical group lists; hide it when fewer than 20 items.
- UI (commonMain, Compose): a slim vertical strip on the right edge of the Library list/grid and the group lists with the letters (A-Z and #; letters that do not occur are dimmed and skipped), touch and drag along the strip scrolls the list to that letter instantly (LazyGrid/LazyColumn `scrollToItem`), a large bubble beside the finger shows the current letter, haptic tick on letter change where an interface exists (small `Haptics` interface, no-op default), the strip fades out a moment after use and appears while scrolling; it must not steal taps from the list edge outside its width (24 dp, extend the touch area to 40 dp), must clear the bottom bar and the mini player, and respect the list's bottom padding. Works with the three layouts (large covers, small covers, list). Accessibility: the strip exposes scroll-to-letter actions (semantics custom actions for each present letter) and a content description "Jump to letter".
- Tests: the pure rules (articles, '#' group, missing letters, fraction mapping both ends, unsorted input is not trusted: build from the sorted list), view-model wiring for the sort-dependent visibility.
