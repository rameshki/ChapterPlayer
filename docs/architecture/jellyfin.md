J2 (progress reporting, queue, marks, three-copy mirroring) is built and host-tested (PR in review); its phone check on a real server (plan Task 15) is open; J3 (Quick Connect, downloads) follows. - Jellyfin (J1 built on `stage-j/j1`, PR #86, Tasks 1 to 8 of `docs/superpowers/plans/2026-11-08-jellyfin-j1-j2.md`; add, sign in again, sync, browse and stream; J2 (Tasks 10 to 14, branch `stage-j/j2`) sends progress back, see the end of this paragraph; host-tested against synthetic fixtures only, not yet run against a real Jellyfin server): `ServerSource.JELLYFIN` (last; Room unchanged), book ids `jf_<item id>` (`domain/jellyfin/JellyfinBooks.kt`). Labels for a kind of server go through `serverKindName` (`domain/browse/ServerNames.kt`). Source badges show for any two kinds of server; the Jellyfin pill is "JF" (palette `jellyfinBadge` / `jellyfinBadgeBg`). Jellyfin covers are anonymous (`CoverAuth.NONE`, only under the server's own address). The token travels only in `Authorization: MediaBrowser ...` (`jellyfinAuthHeader`, `domain/jellyfin/JellyfinAuth.kt`; never in a URL, never `X-Emby-*`), with the DeviceId `chapterplayer-<install id>-<server row id>` (`jellyfinDeviceId`; `InstallId` = `PlexClientIdentifier`'s stored value). `data/remote/jellyfin`: `JellyfinApiService` (its `getPublicInfo` checks the status and decodes the text itself, so it also works on the probe client, which has no JSON converter), DTOs, `fetchAllAudiobooks` (pages of 200), `JellyfinSignIn` (public info on the probe client, version gate `checkJellyfinServer`, identity check against `ServerStatusRecord.jellyfinServerId` on Sign in again, then `AuthenticateByName` and the Books views; texts in `domain/jellyfin/JellyfinTexts.kt`); `JellyfinLibrarySource` (`data/source`, mapping in `domain/jellyfin/JellyfinMapping.kt`; per-view failures in `failedLibraries`; the last snapshot's user data, under 60 s old, answers `fetchAllProgress`; 401 blanks the token like Plex; the sync merges its progress like ABS, no bookmarks); setup in `ui/settings/JellyfinSetup.kt` (`JellyfinSetupHandler`, row id made before sign-in) and `JellyfinSignInSection.kt`; Servers page Test connection reads only the public info. The server id kept at the first sign-in is required: setup fails when it cannot be kept, Sign in again and an address change refuse without it, and a sync first checks the address's public info names it before any token goes out (calls outside a sync are not checked). Playback: `startPlayback` (one track, `domain/jellyfin/JellyfinPlayback.kt`: static stream address, mime table, new play session id) and an explicit Jellyfin arm in Android's `openAuthorized` and iOS's `StreamAuthorizer` (`jellyfinStreamHeader`; 401 blanks the token, 403 not allowed). Three kinds: tie order ABS, Jellyfin, Plex (`kindRank`); Jellyfin cannot download until J3 (`ServerSource.canDownload`, `SourceChoice.forDownload`, used by `chosenDownloadSource`, `downloadableMembers`, the Download from card, bulk Download and the menus); fixtures in `fixtures/jellyfin`. J2 (host-tested only, not yet run against a real server): rules in `domain/jellyfin/JellyfinProgress.kt` (`jellyfinLivePlan`, `jellyfinPushPlan`, `inThresholdBand`, `thresholdsOf`); the live session reports through `/Sessions/Playing` (first report of a load), `/Sessions/Playing/Progress` (`timeupdate`, or `pause` with IsPaused) and `/Sessions/Playing/Stopped` (always with PositionTicks; at the end itself when the close is within 1 s of the end), and where the server's audiobook thresholds would lose the place (the first `MinAudiobookResume` minutes or the last `MaxAudiobookResume`, read from `/System/Configuration` with each sync, unreadable keeps the last known else 5 / 5) and on every pause the exact `POST /UserItems/{Id}/UserData` write follows; an unknown session throws so the position is queued; a book set finished while loaded pins its session (sends nothing) until set not finished. Queued positions and mirrors go only through the UserData write (no session, no thresholds), dated with `pushProgress`'s new `playedAtMs` (the row's time; for a mirror the source copy's `lastPlayedAt` when older, `BookRepositoryImpl.playedAtOf`); finished is `POST /UserPlayedItems/{Id}`; Mark as not finished writes position 0 with `Played = false` (`DELETE /UserPlayedItems` stays in the service for the server check). Jellyfin is a mark target (`MARK_TARGETS`) and `ServerProgressRefresher` refreshes ABS and Jellyfin (not Plex). Rows J1 queued (refused as "not yet") are delivered by the flusher as UserData writes, or dropped when the server holds newer listening or after 30 days. Diagnostics shows the copy's user data (`JellyfinReading` on `ServerProgressReading`); `redact()` removes a `MediaBrowser ...` header value
