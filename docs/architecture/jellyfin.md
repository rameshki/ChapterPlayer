- Jellyfin (J1 merged as PR #86, Tasks 1 to 8 of `docs/superpowers/plans/2026-11-08-jellyfin-j1-j2.md`; add, sign in again, sync, browse and stream; J1 writes nothing back to the server; host-tested against synthetic fixtures; since used against a real Jellyfin server): `ServerSource.JELLYFIN` (last; Room unchanged), book ids `jf_<item id>` (`domain/jellyfin/JellyfinBooks.kt`). Labels for a kind of server go through `serverKindName` (`domain/browse/ServerNames.kt`). Source badges show for any two kinds of server; the Jellyfin pill is "JF" (palette `jellyfinBadge` / `jellyfinBadgeBg`). Jellyfin covers are anonymous (`CoverAuth.NONE`, only under the server's own address). The token travels only in `Authorization: MediaBrowser ...` (`jellyfinAuthHeader`, `domain/jellyfin/JellyfinAuth.kt`; never in a URL, never `X-Emby-*`), with the DeviceId `chapterplayer-<install id>-<server row id>` (`jellyfinDeviceId`; `InstallId` = `PlexClientIdentifier`'s stored value). `data/remote/jellyfin`: `JellyfinApiService` (its `getPublicInfo` checks the status and decodes the text itself, so it also works on the probe client, which has no JSON converter), DTOs, `fetchAllAudiobooks` (pages of 200), `JellyfinSignIn` (public info on the probe client, version gate `checkJellyfinServer`, identity check against `ServerStatusRecord.jellyfinServerId` on Sign in again, then `AuthenticateByName` and the Books views; texts in `domain/jellyfin/JellyfinTexts.kt`); `JellyfinLibrarySource` (`data/source`, mapping in `domain/jellyfin/JellyfinMapping.kt`; per-view failures in `failedLibraries`; the last snapshot's user data, under 60 s old, answers `fetchAllProgress`; 401 blanks the token like Plex; the sync merges its progress like ABS, no bookmarks); setup in `ui/settings/JellyfinSetup.kt` (`JellyfinSetupHandler`, row id made before sign-in) and `JellyfinSignInSection.kt`; Servers page Test connection reads only the public info. The server id kept at the first sign-in is required: setup fails when it cannot be kept, Sign in again and an address change refuse without it, and a sync first checks the address's public info names it before any token goes out (calls outside a sync are not checked). Playback: `startPlayback` (one track, `domain/jellyfin/JellyfinPlayback.kt`: static stream address, mime table, new play session id) and an explicit Jellyfin arm in Android's `openAuthorized` and iOS's `StreamAuthorizer` (`jellyfinStreamHeader`; 401 blanks the token, 403 not allowed). Three kinds: tie order ABS, Jellyfin, Plex (`kindRank`); Jellyfin cannot download until J3 (`ServerSource.canDownload`, `SourceChoice.forDownload`, used by `chosenDownloadSource`, `downloadableMembers`, the Download from card, bulk Download and the menus); fixtures in `fixtures/jellyfin`
